# Empire of Angels III — Việt hóa

Dự án chuyển ngữ Empire of Angels III sang tiếng Việt có dấu.

**Trạng thái:** Đang dịch dữ liệu. Chưa có patch tiếng Việt có thể chạy trong game; cần tiếp tục xử lý font, mã hóa và kiểm thử Windows.

Tài liệu hướng dẫn: `AGENTS.md`, `docs/CLOUD_HANDOFF.md`, `docs/PROGRESS.md`.

Đây là repo dành cho dữ liệu dịch và công cụ kiểm tra. Không có file thực thi của game.
